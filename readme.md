# Marble Race 

A 3D marble race game built with Unity's Universal Render Pipeline(URP) template for the *Intro to Game Development* class at the University. 
 

## What it is

Simulates a physics-based marble race where marbles roll through a track filled with obstales like: 

    - Squares
    - Cylinders 
    - Ramps 
    - Roman Arch Finish Line. 

The goal is for the marbles to traverse the track and cross the finish line.

## Features 
- Built with *Unity 6.5 (6000.5.9f1)* using the *Universal 3D Temaplate* 
- Real-time physics with Unit's Rigidbody system. 
- Obstacle course with interactivve track elements. 
- Automatic marble drop simulation. 

## What it needs to work

To open and run this project it needs: 

- **Unity 6.5 (6000.5.9f1)** or newer *(older versions may work but are not tested)* 

- The **Universal Render Pipeline (URP)** package, it's included in the template. 

- A devide capable of running Unity. 

- When file opens simply press play on the scene so the game executes automatically the marbles will drop and race, no user input needed.
